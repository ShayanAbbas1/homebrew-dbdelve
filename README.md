# homebrew-dbdelve

Homebrew tap for [DBDelve](https://github.com/ShayanAbbas1/dbdelve), a native
macOS database client for Postgres, MySQL and SQLite.

```sh
brew install --cask ShayanAbbas1/dbdelve/dbdelve
```

`Casks/dbdelve.rb` is generated by `dev/release.sh` in the main repository,
which rewrites it whole on every release so the version and the checksum can't
drift apart. Don't hand-edit it here — the next release overwrites it.
